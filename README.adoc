= OpenShift Virtualization Workshop

A focused hands-on workshop covering OpenShift Virtualization (OCP Virt) for running virtual machines alongside containers on the same platform.

== Workshop Overview

This workshop demonstrates how to run virtual machines on OpenShift using OpenShift Virtualization (based on KubeVirt). Learn how VMs integrate with Kubernetes primitives and can be managed with the same tools used for containers.

**Duration:** 45-60 minutes total

=== Workshop Content

* *link:content/modules/ROOT/pages/index.adoc[Setup & Overview]* (10-15 min) - Lab access, cluster verification, virtualization installation check
* *link:content/modules/ROOT/pages/11-virtualization.adoc[OpenShift Virtualization]* (20-25 min) - VM creation with InstanceTypes, pod integration, unified monitoring, networking with Services and Routes, live migration, VM cloning, and snapshots
* *link:content/modules/ROOT/pages/99-conclusion.adoc[Wrap Up]* (5 min) - Summary, key takeaways, next steps

=== What You'll Learn

* Create virtual machines using cloud-style InstanceTypes
* Understand how VMs run as pods in Kubernetes
* Use the same networking (Services, Routes) for VMs and containers
* Monitor VMs with the same Prometheus stack as containers
* Perform live migration for zero-downtime node maintenance
* Clone VMs for rapid dev/test provisioning
* Use snapshots for point-in-time rollback before patches or changes
* Manage everything with familiar `oc` commands

== Local Development

=== Using local-build scripts (Recommended)

From the repo root, build and preview the workshop with Podman:

[source,sh]
----
./local-build/up.sh
----

Open http://localhost:8080/index.html in your browser.

Other commands:

[cols="1,2"]
|===
| `./local-build/build.sh` | Generate the static site into `./www/` using `site.yml`
| `./local-build/serve.sh` | Serve `./www/` with httpd in Podman (port 8080)
| `./local-build/stop.sh` | Stop the local httpd container
| `./local-build/reset.sh` | Stop, rebuild, and serve again
| `./local-build/status.sh` | Show container status
|===

Optional environment variables (see `local-build/_common.sh`):

* `SHOWROOM_PORT` — host port (default `8080`)
* `SHOWROOM_PULL=1` — pull the httpd image before starting
* `SHOWROOM_SITE_YML` — alternate Antora playbook (default `site.yml`)

=== Using Antora CLI directly

[source,sh]
----
npm i -g @antora/cli@3.1 @antora/site-generator@3.1
antora generate site.yml --stacktrace
----

Output is generated in `./www/`. Serve with `./local-build/serve.sh` or any static file server.
